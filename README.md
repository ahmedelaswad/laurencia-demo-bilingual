# Omani Seaweed Database: bilingual Laurencia demonstration

Bilingual (English / Arabic) demonstration website for the HMTF 2027 proposal (priority 3.1.9, Omani biota database). The language button switches the whole interface and the content; scientific names stay in Latin.

- **Records:** 43 Omani herbarium records from GBIF (accessed 6 November 2026) and the SQU voucher SW-R1 (Elaswad et al. 2026, *Phycology* 6: 90).
- **DNA barcodes:** rbcL, COI-5P and 18S rRNA sequences from GenBank and unpublished SQU data.
- **Photographs:** SW-R1 (Elaswad et al. 2026, CC BY) and reference photos from AlgaeBase, used for demonstration only.
- **Assistant:** a built-in chat panel that answers questions from the same data, in English or Arabic. It runs in the browser and sends nothing anywhere.

Detailed English version: `../laurencia-demo/`

The whole site runs in the browser. There is no server or database to install: `index.html` and the `images/` folder are all it needs.
